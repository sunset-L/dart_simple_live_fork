# Simple Live Web

网页客户端，参考 Windows 客户端的左侧导航、平台标签、直播网格和设置列表。包含首页、关注、分类、我的，以及数据同步、历史记录、屏蔽词管理和独立标签页播放器。后端继续使用 Dart，共享客户端平台解析与弹幕协议。

## 运行

需要 Node.js 22.12+（本机使用 24）及 Dart 3.10+。本仓库的 Flutter 3.47.1 已包含所需 Dart SDK。

默认使用本地开发模式，在本目录执行（已安装依赖时无需重复获取）：

```sh
npm ci
dart pub get
npm run server
```

另开终端执行 `npm run dev`，打开 Vite 输出的地址（默认 `http://127.0.0.1:5173`）。`/api` 和 `/ws` 转发到本机 Dart 服务，默认端口为 23236。只在明确需要打包或部署时执行 `npm run build`；Dart 服务也可提供已构建的 `dist` 静态页面。

`scripts/serve.mjs` 优先使用 `DART_EXECUTABLE` 指定的 Dart 可执行文件，其次使用仓库 `.task-cache/fvm/versions/3.47.1` 内的 SDK，最后查找 PATH 中的 `dart`。`PORT` 可修改监听端口。服务仅绑定本机 IPv4，不应直接部署到公网或解除来源校验。

若更改 API 端口，为两个终端设置相同的 `PORT` 环境变量。前端开发端口可用 `npm run dev -- --port 23237` 指定；升级旧版时可先复用原网页端口，以便自动迁移该地址下的旧浏览器数据。

关注、标签、历史和屏蔽词保存在本机 Dart 服务的固定数据目录，不随前端或 API 端口改变；`localhost`、`127.0.0.1`、开发模式和正式模式也共用这一份数据。Windows 默认目录为 `%APPDATA%/simple-live-web/library.json`；其他系统使用 `$XDG_DATA_HOME/simple-live-web` 或 `$HOME/.local/share/simple-live-web`。可通过 `SIMPLE_LIVE_DATA_DIR` 指定目录，同一份数据的各个服务必须使用相同目录。

## 核心库与原生依赖

直播列表、搜索和分类使用相对路径依赖 `../simple_live_core`，不复制平台解析逻辑。React + TypeScript 负责浏览器界面，本地 Dart 服务处理跨域接口请求。

默认启动通过 `dart run` 构建 QuickJS 原生依赖，斗鱼签名取流也需要它。Windows 需要 Visual Studio 2022 Build Tools 的 C++ 桌面开发工具与 Windows SDK。Linux/macOS 需要相应 C 工具链。

`npm run server:native` 是默认完整模式的别名。没有原生工具链时可以使用降级模式：

```sh
npm run server:lite
```

降级模式直接运行 Dart VM，支持同步功能及不依赖 QuickJS 的平台接口，**不支持斗鱼播放、抖音推荐列表及分类下直播列表**。本机已安装 Build Tools，完成 QuickJS 构建并启动完整模式服务；不代表所有平台真实直播验收通过。平台接口仍受网络、反爬策略和核心库实现影响。

## 播放页

- 从直播列表、关注、历史进入独立播放标签页；同一页面重复点击同一房间会聚焦已有标签页，不重复加载。
- 使用 ArtPlayer（查询时 GitHub 约 4.2k stars）、hls.js（约 17k stars）、flv.js（约 23k stars）与 ArtPlayer 弹幕插件。HLS、FLV 引擎按需加载。
- 支持哔哩哔哩、斗鱼、虎牙；提供清晰度、线路选择、刷新取流、播放暂停、音量静音、系统全屏、网页全屏、原生画中画、画面适应及控制锁定。
- 无必要请求头时优先直连，失败自动改用 Dart 代理；随后尝试其他线路，保留可恢复的上一线路，全部失败后最多自动刷新两次。换源播放成功后校正选择状态。已知过期地址会提前刷新。
- Dart WebSocket 中继平台弹幕，提供断线重连、聊天列表、B站实时 SC、弹幕开关、透明度、字号、粗细、速度、区域、边距、福袋过滤和屏蔽词。
- 屏蔽词与客户端同步；`/表达式/` 使用线性时间 RE2 引擎，避免复杂表达式冻结主线程。反向引用、前后查找等 RE2 不支持的规则不会生效，原规则仍保留在同步数据中。
- 关注和首次播放历史保存到本地服务；其他标签页及不同端口页面会同步更新。提供房间链接、播放直链、分享和分辨率、帧数、缓冲等播放信息。
- 关注页与播放页的关注侧栏显示直播中、未开播或查询失败；状态通过核心库接口查询，关注页可手动刷新。可见页面每轮查询结束后 60 秒自动刷新，服务端缓存状态 30 秒，不把查询失败当作未开播。
- 首页、关注和历史共用封面卡片：头像与主播名叠在封面下缘，火焰图标显示热度，标题放在封面下方。关注与历史显示平台图标与名称，首页及分类已有平台筛选，不重复展示平台。整张卡片进入直播间，关注及标签按钮独立操作；关注列表按全部、直播中、未开播筛选，全部列表的直播中主播优先，同组保持原关注顺序，不展示房间号。
- 新关注先保存，再补齐头像；已有空头像在关注页查询资料后自动保存。卡片资料缓存 10 分钟，首页头像按可见区域加载并限制并发；哔哩哔哩直接读取公共房间信息，不请求弹幕凭据。未取得头像或图片加载失败时不显示默认图标占位。桌面侧栏中部边缘悬停显示收起和展开箭头，键盘聚焦时保持可见，收起后保留图标导航。
- 卡片统一网格与固定封面比例，切换筛选不因滚动条或图片尺寸改变卡片大小，桌面悬停时封面轻微放大。手动刷新保留旋转动画，结束后提示成功、失败或部分失败；没有自定义标签时隐藏标签栏。从关注进入历史时保留关注导航高亮与返回入口。
- 右上角主题菜单支持浅色、深色、跟随系统及六种主题色，浏览器保存外观选择，播放页使用相同主题色。
- 直播间视频与弹幕区紧凑并排，主播资料和关注操作放在视频下方；小屏改为上下排列。直播信息和缓冲共用播放器加载动画，双击与 F 键只切换网页全屏，系统全屏从播放器图标进入，Esc 退出网页全屏。关注图标立即同步本地数据并识别房间别名；聊天显示“用户名: 内容”，正文保留平台颜色，滚动弹幕支持原色、白色及自定义颜色。
- 代理只接收服务端登记的上游地址，限制并发和清单大小，对实际连接 IP 做公网校验，跨主机跳转去除认证头。不要向不信任的人分享带签名的播放直链。

### 当前边界

- 按约定不做移动端触摸手势。抖音播放、定时关闭、系统亮度与方向控制、原生悬浮窗、录制和投屏未移植。
- 没有网页账号登录或发弹幕入口，无法保证账号专享画质；SC 仅展示当前连接收到的消息，不拉取历史。
- FLV、HEVC 解码取决于浏览器与系统，建议桌面 Chrome/Edge；浏览器禁止自动播放时需手动播放。原生画中画只显示视频，不包含网页弹幕。
- 弹幕滚动时长范围为插件支持的 1–10 秒；播放器设置保存在本浏览器，不属于客户端备份同步范围。
- 服务仅监听本机，当前不是供局域网手机直接访问的部署方案。

```text
  routes/              静态文件、目录及播放接口
  playback/            取流缓存、代理登记与媒体转发
  danmaku/             弹幕 WebSocket 中继

```

## 数据同步

- **WebDAV**：检查连接、上传和恢复，路径与客户端一致，为 `<WebDAV 根路径>/simple_live_app/backup.zip`。根地址不要重复填写 `simple_live_app`。
- **本地 ZIP**：导入和导出客户端兼容备份，可离线使用。
- **局域网**：手动填写运行中客户端的 IPv4 地址，通过其 23234 端口检查连接和推送。现有客户端协议只有写入接口，没有读取接口，因此此处不提供拉取或自动设备发现；客户端数据进入网页使用 WebDAV 或 ZIP。
- 同步范围：关注与标签（同时处理）、历史记录、弹幕屏蔽词。默认合并，覆盖需要确认；云端上传以本地所选数据替换对应文件。
- 历史合并保留相同 ID 中时间较新的记录。ZIP 先完整解析并校验，再一次性写入本地数据文件；不合法备份不会清空本地数据。限制压缩包及解压内容为 20 MB。
- WebDAV 上传先读现有备份，保留未选文件、客户端设置和账号文件，不在网页导入或展示这些敏感字段。新建网页备份不包含账号 Cookie 或 App 设置。已有备份中的敏感文件会原样保留在上传内容中。
- WebDAV 凭据只保留在当前页面内存，不写入浏览器存储或服务日志。推荐 HTTPS；HTTP 连接会额外警告。
- 服务提供强 ETag 时使用 `If-Match` 检测并发更新；新文件使用 `If-None-Match`。不提供强 ETag 的服务器需再次确认，无法保证多设备并发安全。
- 现有客户端的关注、标签等是独立写入接口，不能事务回滚。局域网部分成功时会明确提示已传输项目，需要重试完成剩余同步。

关注、标签、历史和屏蔽词通过 `/api/library` 写入固定的本地数据文件。保存成功后才更新界面；使用版本检查、跨进程文件锁和临时文件替换，避免多端口或多标签页互相覆盖。可见页面每 5 秒检查更新，回到页面时也会重新读取。文件损坏时停止写入，保留原始数据导出和确认清除入口；连接失败时只提供重试。

首次访问新版时，自动合并当前浏览器来源下旧版 `localStorage` 数据，保留原始数据并记录迁移标记。浏览器不能直接读取其他端口的旧存储，因此已有旧关注的每个地址需要用新版访问一次；之后切换任意端口无需再次迁移。清除浏览器站点数据不会删除服务端数据文件，但会清除主题和播放器设置。
